# Changelog

All notable changes to DAYFRAME are documented here.

## 3.0.0 — Theme Studio

- Added four animated background palettes: Midnight, Ocean, Plum and Forest.
- Added five icon accent colors: Violet, Cyan, Mint, Rose and Amber.
- Saved appearance preferences locally so they persist after app restarts.
- Added smooth color transitions and spring feedback when selecting theme swatches.
- Applied the selected icon accent to navigation icons and the DAYFRAME mark.
- Kept the local-first planner, focus timer, insights and GitHub release checker.

## 2.0.0 — Update Center refresh

- Set the application version to 2.0.0 (version code 2).
- Added a visible last-checked timestamp to the in-app Update Center.
- Added a compact installed-versus-latest version comparison.
- Reworked the in-app update history to explain the 2.0.0 changes.
- Clarified that a source build is not a downloadable release until GitHub Releases contains an APK asset.
- Kept the live GitHub release feed, workflow status, release notes and system APK download flow.

## 1.0.0 — First source release

- Introduced the local-first daily task planner.
- Added focus timer presets, pause, resume and reset.
- Added local persistence for tasks and completed focus sessions.
- Added seven-day focus insights.
- Added responsive portrait and wide / landscape navigation.
- Added animated launch sequence and Compose screen transitions.
- Added live GitHub Releases / Actions status checking in About.
- Added system Download Manager integration for published APK assets.
- Added project identity, launcher icon, documentation and Android CI.

 > Current source version: 3.0.0. An installable APK is published separately through GitHub Releases after the release workflow succeeds.
